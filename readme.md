# Smart Student Performance Prediction System

## Day 1 - Python Prototype

This prototype collects student information and calculates
a basic performance score using attendance, study hours,
internal marks, and assignment completion.

## Technologies

- Python

## Current Features

- Student data input
- Performance score calculation
- Performance classification
- Basic recommendations

## Current Limitation

This version does not use Machine Learning or Tkinter.
These features will be added in later stages.
